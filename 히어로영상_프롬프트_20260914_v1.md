# 히어로 루프 영상 프롬프트 (Google Flow / Veo 3.1) — v1

> 2026-09-14 / 대상: `assets/hero.jpg`(2200×933 플랫 일러스트)를 조용히 무한 루프되는 배경 영상으로.
> 규칙: nanobanana-veo-prompt Ver 13.0 (파일명 선행, 영어 본문, 부정어 금지, 음악 금지 단일 선언문, Textless).

## Google Flow 작업 순서 (끊김 없는 루프의 핵심)
1. Flow 새 프로젝트 → 모드 **"Frames to Video"** 선택. 모델 Veo 3.1, 길이 **8초**, 가로 16:9.
2. **시작 프레임**과 **끝 프레임 모두에 `hero.jpg`를 동일하게 업로드**한다. 첫 장면과 마지막 장면이 같아지므로 재생을 이어 붙였을 때 이음새가 사라진다.
3. 아래 프롬프트의 **첫 줄(파일명)은 제외**하고 본문만 붙여 넣는다.
4. 4개 결과 중 사람 실루엣이 흔들리지 않고 억새·낙엽만 움직이는 것을 고른다. 인물이 걸어가 버리면 루프가 깨지므로 재생성.
5. (선택) 결과가 마음에 들면 "Extend"로 8초를 추가하지 말고, 같은 클립을 웹에서 `loop` 재생한다. 16초가 필요하면 v1 결과의 마지막 프레임을 시작·끝 프레임으로 다시 넣어 두 번째 클립을 만든다.

## 웹 적용
```bash
# 용량 최적화(무음, 1600px, 약 2~3MB 목표) — 결과물 hero_loop.mp4 / hero_loop.webm
ffmpeg -i flow_output.mp4 -an -vf "scale=1600:-2" -c:v libx264 -crf 24 -pix_fmt yuv420p -movflags +faststart assets/hero_loop.mp4
ffmpeg -i flow_output.mp4 -an -vf "scale=1600:-2" -c:v libvpx-vp9 -b:v 0 -crf 34 assets/hero_loop.webm
```
index.html의 `<img class="hero-photo" src="assets/hero.jpg">` 자리에 `<video class="hero-photo" autoplay muted loop playsinline poster="assets/hero.jpg">` + `<source>` 2개로 교체. `prefers-reduced-motion`이면 정지 이미지 유지. (요청 시 반영)
